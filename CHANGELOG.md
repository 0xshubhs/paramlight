# Changelog

## 0.1.0

- Argument colors with a suffix symbol for JavaScript, TypeScript, JSX, TSX, Python, Rust, Go, C, C++, Java, C#, PHP and Ruby.
- Boxes for fields, readonly fields, constants and mutable globals.
- Shadowing warnings for declarations that hide an argument, an outer local, a global, a constant or a field.
- Hover explanations with the declaration line.
- Document formatter: bundled Prettier for JavaScript, TypeScript and PHP; ruff or black, rustfmt, gofmt, clang-format, google-java-format and rufo for the other languages; per-language overrides.
